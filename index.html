Steam Wishlist Sorter

Runs locally · your data is not sent to third-party servers

Progress saved in this browser

Your data never leaves the browser. The only external request the application makes at any point is loading game covers from the Steam CDN over a public URL; it is switched off by the “Load covers” toggle. The import straight from an account is asked for by the local server on your own machine: it goes to Steam, to nobody else, and only when you press the button.

Load from Steam

The easiest way for a public wishlist

Automatic import works when “Game details” are public.

What if it is private?

Open your Steam profile, choose “Edit profile”, then “Privacy Settings”, and set “Game details” to Public. If you would rather not open it, the userscript under “Other import methods” reads the page you are logged into and works with a private list.

Open Steam settings ↗

One title, one request, so a long list takes minutes. Everything that has already arrived is saved — stopping loses nothing.

  1. Open your Steam profile and choose “Edit profile”.
  2. Open “Privacy Settings”.
  3. Set “Game details” to Public.
  4. Come back here and press “Check again”.

I don’t want to make it public

Collect the list from the Steam page itself. The userscript reads the wishlist page you are logged into, so the privacy setting does not matter, and it makes no network request of its own.

  1. Install Tampermonkey — it exists for Chrome, Edge, Firefox and Opera.
  2. Install the script “steam-wishlist-export.user.js” from the repository.
  3. Open your wishlist page and press “Collect the list”, then “Download JSON”.
  4. Come back here and pick that file under “Other import methods”.

      Settings

      Step 2 of 4

      First, roughly group games by interest

      You will see one game at a time and put it somewhere on a scale of five levels — or straight onto the list of games to remove from the wishlist.

      • This is what keeps the sorting short: games are only ever compared inside their own group, so a rough split now saves hundreds of questions later.
      • Do not think too long. A category can be changed at any time — walk back to the game with “Previous”, or change it on the result screen.

      Step 3 of 4

      Now choose between two games

      Two games at a time, both from the same group. Pick the one you want more — the keys A and D, or the arrows.

      • If you want them equally, say “About the same”: that is an answer too, and the sorting uses it.
      • A hard pair can be postponed with Space; it comes back once the easy ones are answered.
      • Finish whenever you like. Every answer is saved, and the result is ready to look at at any moment — finished or not.
