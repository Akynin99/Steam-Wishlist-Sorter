# Steam Wishlist Sorter

Локальное веб-приложение, которое помогает упорядочить список желаемого в Steam
попарными сравнениями и получить честный итоговый рейтинг.

## Запуск

ES-модули не загружаются со схемы `file://`, поэтому приложение открывается
с локального HTTP-сервера. Сервер входит в комплект — это `server.js` на чистом
Node, без единой зависимости.

- Windows: запустите `start.bat`.
- Иначе: `node server.js` и откройте `http://localhost:8080/`.

Node нужен только для сервера и тестов, само приложение работает в браузере.
Тесты: `node --test`.

## В разработке

Готовы ядро ранжирования, импорт и интерфейс: экран импорта, распределение по
категориям и попарные сравнения. Впереди — экспорт результата в JSON, CSV и текст,
userscripts для страницы Steam и развёрнутый README со скриншотами.

## Приватность

Пользовательские данные никогда не покидают браузер. Единственный внешний запрос
за всё время работы приложения — загрузка обложек игр с CDN Steam по публичному
URL; этот запрос отключается тумблером в настройках.
