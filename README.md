# Steam Wishlist Sorter

Локальное веб-приложение, которое помогает упорядочить список желаемого в Steam
попарными сравнениями и получить честный итоговый рейтинг.

## В разработке

Проект находится в стадии разработки: сейчас в репозитории только каркас,
реализации пока нет. Развёрнутое описание — установка, запуск, скриншоты,
формат импорта и экспорта, userscripts — появится здесь по мере готовности.
